# `EXEMPLAR_WEB_LIBRARY`
> NodeJS Module Library Example

## Usage

### Install

```sh
npm install @nethreed/exemplar_web_library
```

### Import

```mjs
import exemplar_web_library_todo from '@nethreed/exemplar_web_library';

console.log( exemplar_web_library_todo( )); // 3
```
